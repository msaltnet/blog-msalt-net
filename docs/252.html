구글 Keep 줄바꿈 문자로 두줄 띄워지는 문제

2018. 5. 3. 23:31

언젠가부터, 구글 Keep에 윈도우 텍스트 에디터에서 작성한 글을 복사해서 저장하면 문단 사이에 빈 줄이 하나씩 더 들어간다. 구글 Keep 애용자로서 항상 불편을 겪고 있었는데, 혹시나 해서 줄바꿈 문자를 강제로 변경해 봤는데, CRLF을 LF로 바꾸니까 잘된다!

평양 냉면 먹고 싶어서, 예전에 태평로에서 먹은 평양 냉면 사진 올려본다.ㅋ

주로 VS CODE 나 One note를 사용해서 글을 작성하고, 구글 Keep으로 보관을 하다가 카톡이나 블로그에 공유하기도 하는데 언젠가부터 이상하게 구글 Keep으로 들어가기만 하면 줄바꿈이 두줄로 변경되었다. 처음엔 대수롭지 않게 생각했는데 카톡으로 보낼때도 보기가 않좋아서 검색을 해봤는데, 비슷한 어려움을 호소하는 사람을 못 만났다. 나만 그런건가…그러다 문득 설마…라는 마음으로 줄바꿈 문자를 CRLF에서 LF 로 바꾸니까 잘된다.ㅋㅋㅋ

뭐여. 리눅스 스타일인가…웹 인데…;;

줄바꿈 문자, 개행 문자, 새줄 문자가 무엇인지, 어떤 히스토리를 가지고 있는지는 따로…

새줄 문자(newline)는 텍스트의 한 줄이 끝남을 표시하는 문자 또는 문자열이다. 개행 문자, 줄바꿈 문자(line break), EOL(end-of-line)과 같은 뜻이다. 기종이나 운영 체제에 따라 새줄 문자를 나타내는 코드가 다를 수도 있다. 그래서 텍스트를 다른 시스템으로 전송할 때 새줄 문자의 치환 작업도 필요하다.위키백과 새줄 문자

추가 확인 내용

우연히 다른 사이트에서도 비슷한 문제가 발생해서, 이것은 Keep의 문제가 아니라 브라우저의 문제일 수도 있겠다는 생각이 들었다. 아니나 다를까 IE, Firefox는 잘된다. 헐..ㅋ 크롬 엔진만 줄바꿈 문자 인식 방법이 다른듯…

아무래도 나만 그런것 같지가 않아 좀 더 찾아봤는데, 외국에서도 이슈가 많이 되고 있다. 해결책이 다양한데, 나처럼 텍스트 에디터에서 CR문자를 제거하거나, 브라우저를 바꾸거나, 전용앱을 사용하는 방법이 많이 회자되고 있는것 같다.
