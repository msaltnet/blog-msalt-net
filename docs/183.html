타이젠 어플리케이션 개발 시작하기

2016. 12. 26. 18:18

샘플을 이용해서 타이젠 어플리케이션 개발 시작하기 좋은 방법을 소개 합니다. 타이젠 어플리케이션은 크게 웹 어플리케이션Web Application과 네이티브 어플리케이션Native Application이 있습니다.

둘 다 장단점이 있으며, 적절히 선택해서 개발하면 됩니다. 둘 다 사용할 수도 있습니다. 예를 들면 서비스 앱은 네이티브로, UI 앱은 웹으로 구성해서 하나의 패키지로 묶을 수도 있습니다. 그렇게 묶인 패키지를 하이브리드 어플리케이션이라고 합니다.

[

](https://developer.tizen.org/community/tip-tech/packaging-hybrid-application?langredirect=1)

웹이든, 네이티브든 쉽게 시작하기 좋은 방법을 소개합니다. 바로 샘플을 이용하는 것입니다! 샘플 코드를 가져다가 내가 원하는 대로 수정해서 사용하거나, 샘플코드를 보고 사용방법을 확인 할 수 있습니다.

앱 개발을 어떻게 해야 할지 샘플 앱의 구조를 확인해 보는 것도 도움이 됩니다. 타이젠은 온라인 샘플을 제공하고 각각의 샘플 어플리케이션에 대한 가이드를 개발자 사이트에서 제공합니다.

[

](https://developer.tizen.org/development/sample/native/UI/%28Circle%29_Alarm_Widget)

그리고 하나 더! 샘플 코드를 검색해 보세요. 내가 사용하는 API의 사용법이 궁금하거나 사용 사례를 확인 하고 싶을 때 샘플 코드를 검색해 보면 도움이 됩니다. http://tizen.msalt.net/source 에서 검색하면 됩니다! 제가 개인적으로 온라인 샘플 코드를 다운받아서 오픈그록을 구성해 봤습니다.ㅎ
