# 메신저 앱 소개

총 1개

기술 이야기

텔레그램 기반의 혁신적인 메신저 소셜라이저 소개

웹앱을 대화방에서 바로 공유하는 텔레그램 기반의 혁식적인 메신저 소셜라이저를 소개합니다. 웹앱이란? 웹 애플리케이션 Web Application의 줄임말로 말그대로 HTML5, JavaScript등의 웹기술을 이용하여 만든 애플리케이션입니다. 일반적으로 브라우저에서 실행되기 때문에 운영체제(OS)의 구분 없이 동일한 앱을 사용할 수 있는 것이 장점입니다! 소프트웨어 공학적 관점에서 웹 애플리케이션(web application) 또는 웹 앱은 인터넷이나 인트라넷을 통해 웹 브라우저에서 이용할 수 있는 응용 소프트웨어를 말한다.위키백과, 웹 애플리케이션 웹앱을 공유? 공유하기 버튼 아시죠? 누르면 사진이나 동영상 같은 것을 친구들에게 메신저나 문자 메세지로 보내는 기능! 웹앱 공유도 같은 개념입니다. 그냥 ..
