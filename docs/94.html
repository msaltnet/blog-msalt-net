고마워서 만든 블로그 개편

2015. 8. 5. 01:26

오랫동안 제대로 관리 못했던 고마워서 만든 블로그를 개편하였습니다. 모양새와 구조도 확바꾸고 내용도 체계적으로 정리하였습니다. 앞으로 운영도 착실하게 잘해서 더 쉽게 많은 도움을 드릴 수 있었으면 합니다.

반응형 스킨으로 교체

부트스트랩을 사용하여 반응형 스킨으로 만들었습니다. 잘 만들어서 공유하려고 하였지만 개인적인 취향이 너무 강하게 적용되어서 가져다 쓰실 분이 있을지 모르겠습니다.ㅠ 혹시나 몰라 공유는 해놨습니다.

티스토리 반응형 웹 스킨 공유

개인 도메인 연결

개인 도메인을 연결하였습니다! blog.delisalt.me 가비아에서 행사 가격으로 1년 6000원에 계약했습니다ㅎ 네이버 블로그(맛소금n블로그)도 연결하고, 맛소금 홈페이지도 만들어서 여러가지 프로젝트를 진행해 보려합니다. 이부분은 다음에 다시 소개를 해드릴께요!

저처럼 블로그를 여러개 사용하시는 분이나 홈페이지에 관심이 있으신 분은 도메인 하나 따서 2차 도메인 연결해보세요. 구글 애드 센스 단가가 올라 간다는 분도 있더라구요~

티스토리 2차 도메인 연결 후기

티스토리 2차 도메인 주소와 DNS 설정법

위 포스팅보시고도 잘 안되시는 분은 댓글로 문의 주시면 도와드릴께요.:)

카테고리 조정 및 글 정리

마지막으로 카테고리를 조정하고 글을 정리했습니다. 오랫동안 편집중이었던 글도 완성하거나 삭제하였고, 불필요한 개인 보호글도 삭제하였습니다. (메리트가 없는것 같아서…ㅎ)

적다보니 딱히 적어 놓을 필요가 없는 내용들이네요.ㅋ

그래도 하나의 마디가 생기고 새로운 장을 여는 기념으로 기록해둔다고 생각하렵니다!

고맙습니다.
