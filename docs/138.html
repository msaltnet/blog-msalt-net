Tizen 2.4 SDK 윈도우 설치

2015. 12. 31. 02:24

Tizen 2.4 SDK 윈도우 설치 해봤습니다. 타이젠 공식 홈페이지에 가셔서 다운받은 다음 설치하면 됩니다. 복잡하지도 않고 어렵지도 않습니다. 예전버전을 설치해보신 분이라면 상전벽해라는 사자성어를 떠올리게 되실겁니다.

따로 정리할 필요가 없다고 생각됨에도 불구하고 불친절하게나마 스샷을 올려둡니다. 없어도 충분히 하실 수 있지만, 낯선 것을 즐기지 않는분들을 위한 어떤 심리적인 효과를 위해서랄까?ㅋ 전 원래 이런 포스팅 잘 안하는데,,, 2.4는 스샷이 없는것 같아서…억지로함!

참고로 전 기어 S2를 오늘 주문했습니다. 내일 올겁니다. 야호~ㅋ 만들어보고 싶은게 너무 많으네욧!

주의할 점

  1. 시간이 오래걸립니다. 마져하고 자야지 생각하면 지금 이시간이 됩니다.

  2. 별로 어렵지 않지만, 환경과 개인차가 존재합니다.
