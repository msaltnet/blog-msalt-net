타이젠 앱 개발자를 위해서 제가 만든 오픈그록 OpenGrok [TizenXRef](https://tizen.msalt.net) 사이트을 소개합니다. 나도 필요하고, 누군가도 필요한 것들을 만들어서 나도 편하게 쓰고, 누군가에게 도움을 주려는 노력 중 하나 입니다.

![](/images/posts/200/002.jpg)

### 오픈그록 OpenGrok 소개

<blockquote>
<p>OpenGrok is a fast and usable source code search and cross reference engine. It helps you search, cross-reference and navigate your source tree.<cite><a href="https://opengrok.github.io/OpenGrok/" target="_blank">OpenGrok Github</a></cite></p>
</blockquote>

생각보다 오픈그록 또는 OpenGrok 으로 검색을 하면 국내 사이트에서는 나오는 것이 별로 없더라구요. 저도 그렇고 주변 사람들, 다른 사업부 사람들도 엄청 유용하게 많이 쓰는 시스템인데요.

![](/images/posts/200/003.jpg)

오픈그록은 빠르고 편리한 코드 검색 시스템입니다. 코드를 검색하고, 코드간의 상호 참조를 사용하여 코드를 둘러볼 수 있습니다. 안드로이드 플랫폼 버전 별로 코드를 확인 할 수 있는 사이트 [AndroidXRef](http://androidxref.com/)도 오픈그록을 사용하고 있습니다.

오픈그록 설치나 사용법은 공식 사이트를 참고해 주시고, [고급진 사용법](http://blog.msalt.net/178)이라고 허접한 포스팅을 남긴 적도 있습니다.

### TizenXRef 소개

[AndroidXRef](http://androidxref.com/)처럼 타이젠 플랫폼별 소스를 이용해서 만들려고 했으나, 음...용량이 생각보다 큰데? 허...돈이...ㅠ.ㅠ 그래서 일단 앱 개발자를 위해서 온라인 샘플 앱 코드만이라도 대상으로해서 만들어 봤습니다.

타이젠 온라인 샘플은 말그대로 온라인으로 제공되기 때문에 SDK에 다운로드 주소가 있습니다. 제 서버에 그 주소의 온라인 샘플을 다운받아서 OpenGrok을 설치 후 색인 작업까지 완료한 것이 [TizenXRef](https://tizen.msalt.net)입니다.

![](/images/posts/200/004.jpg)

앱 개발을 하다보면 API 사용할 일이 많은데, API Reference 도 많은 도움이 되지만, Code Sample을 확인하는 것이 더 쉽게 이해가 될 때가 많습니다. 샘플 앱에서 관련 코드가 어떻게 사용되었는지 확인해보면 많은 도움이 되길래, 저도 사용하고, 누군가도 편하게 쓰시라고 만들었습니다.ㅋ

곧 Tizen 에 .NET 앱이 추가되는데, 그때 나오는 샘플도 올리고, 색인도 새로 진행하도록 하겠습니다. 그럼...도움이 되길 바라며...20000...쿨럭...
