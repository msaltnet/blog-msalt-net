웹앱을 대화방에서 바로 공유하는 텔레그램 기반의 혁식적인 메신저 소셜라이저를 소개합니다.

![](/images/posts/106/002.jpg)

### 웹앱이란?

웹 애플리케이션 Web Application의 줄임말로 말그대로 HTML5, JavaScript등의 웹기술을 이용하여 만든 애플리케이션입니다. 일반적으로 브라우저에서 실행되기 때문에 운영체제(OS)의 구분 없이 동일한 앱을 사용할 수 있는 것이 장점입니다!

<blockquote>
<p>소프트웨어 공학적 관점에서 웹 애플리케이션(web application) 또는 웹 앱은 인터넷이나 인트라넷을 통해 웹 브라우저에서 이용할 수 있는 응용 소프트웨어를 말한다.<cite><a href="https://ko.wikipedia.org/wiki/%EC%9B%B9_%EC%95%A0%ED%94%8C%EB%A6%AC%EC%BC%80%EC%9D%B4%EC%85%98" target="_blank">위키백과, 웹 애플리케이션</a></cite></p>
</blockquote>

### 웹앱을 공유?

공유하기 버튼 아시죠? 누르면 사진이나 동영상 같은 것을 친구들에게 메신저나 문자 메세지로 보내는 기능! **웹앱 공유도 같은 개념입니다. 그냥 아이콘 누르고 공유하면 웹앱이 대화방에서 바로 전달되는 방식이에요.**

![](/images/posts/106/003.jpg)

소셜라이저의 웹앱은 **설치가 필요없고, 대화방에서 바로 실행이 되는 것이 가장 큰 특징입니다!**

### 텔레그램 기반?

**텔레그램이랑 똑같은데 웹앱 공유 기능을 추가한 것입니다~** 텔레그램은 오픈 소스라서 기능을 추가해서 다른 앱을 만드는것이 자유롭거든요. 마음대로 가능합니다. **텔레그램의 기능을 모두 담고있고 동일한 텔레그램 서버를 사용하기 때문에 텔레그램 사용자라면 갈아탈만 합니다.ㅋ**

친구들이 많이 사용하지 않는 것이 최대 불편한 점인데...OTL 요즘 텔레그램이 봇도 지원하고, 스티커 커스텀도 지원해서 사용자가 꾸준히 늘어나는 것 같으니 가까운 친구들에게 소개해서 쓰고 있어요.ㅋㅋㅋ

**일단 텔레그램은 파일 전송도 되고, 동영상 사이즈도 무제한에 각종 봇과 스티커가 있어서ㅋㅋㅋ 카톡과 별개로 세컨 메신저로 사용합니다~ㅎ** 스티커를 직접 쉽게 만들 수 있어서 미친듯이 추가되고 있네요.
