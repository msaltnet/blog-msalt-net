### Ubuntu 16.04 에 몽고DB 설치

<p>공식 사이트에 가면 14.04 버전 설치 방법만 나와있는데, 크게 다르진 않지만...

https://www.digitalocean.com/community/tutorials/how-to-install-mongodb-on-ubuntu-16-04

<pre class="prettyprint">`$sudo apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv EA312927
$echo "deb http://repo.mongodb.org/apt/ubuntu xenial/mongodb-org/3.2 multiverse" | sudo tee etc/apt/sources.list.d/mongodb-org-3.2.list
$sudo apt-get update
$sudo apt-get install -y mongodb-org
$sudo vim /etc/systemd/system/mongodb.service
`</pre>

<p>`/etc/systemd/system/mongodb.service` 파일 내용을 아래와 같이 작성

<pre class="prettyprint">`[Unit]
Description=High-performance, schema-free document-oriented database
After=network.target

[Service]
User=mongodb
ExecStart=/usr/bin/mongod --quiet --config /etc/mongod.conf

[Install]
WantedBy=multi-user.target
`</pre>

<p>아래 커맨드로 컨트롤.

<pre class="prettyprint">`sudo systemctl enable mongodb
sudo systemctl start mongodb
sudo systemctl stop mongodb
sudo systemctl status mongodb
`</pre>

### MongoDB 특정 문자열을 찾는 방법

<p>여러 방법이 있겠지만, 자바스크립트를 사용하듯이 shell에서 아래와 같이 단순한 방법으로 찾는 문자열이 포함된 부분을 화면에 출력할 수 있다.

<pre class="prettyprint">`db.collection.find().forEach(function(item){
    var keyword = '/resource/'; //찾고자 하는 문자열
    var length = keyword.length;
    var string = item.field;
    var substring = '';

    if (!string)
        return;

    var index = string.indexOf(keyword);

    while (index != -1) {
        substring = string.substring(index, index + 50);
        string = string.substring(index+length);
        print(substring);
        index = string.indexOf(keyword);
    }
});
`</pre>

### MongoDB 특정 문자열을 교체하는 방법

<p>상대 경로로 저장되어 있던 리소스의 url을 S3로 바꾸면서 DB에 있는 내용을 모두 바꿔야 해서 사용했던 명령문이다. SQL만 사용하다가 이렇게 사용해보니 완전 기분이 색다르다.ㅋ

<pre class="prettyprint">`db.collection.find().forEach(function(item){
    var keyword = '/resource/';
    var replacement = 'https://s3-us-west-1.amazonaws.com/example/resource/';

    if (!item.field)
        return;

    item.field = item.field.replace(keyword, replacement);
    db.collection.save(item);
});
`</pre>

### MongoDB 기본 커맨드 모음

1.

<p>test 데이터베이스로 이동할때

<pre class="prettyprint">`>use test`</pre>

2.

<p>데이터베이스 목록 출력

<pre class="prettyprint">`>show dbs`</pre>

3.

<p>데이터베이스 상태확인

<pre class="prettyprint">`>db.stats()`</pre>

4.

<p>데이터베이스 shutdown

admin 영억으로 이동후에 셧다운 해야함.

<pre class="prettyprint">`
>use admin
>db.shutdownServer()
`</pre>

5.

<p>데이터베이스 로그아웃

<pre class="prettyprint">`>db.logout()`</pre>

6.

<p>데이터베이스 삭제

<pre class="prettyprint">`>use db, and db.dropDatabase()`</pre>

7.

<p>collection 생성

`capped` 옵션으로 사이즈를 고정 할 수 있으며, 초과되는 데이터는 overwrite 된다.

<pre class="prettyprint">`>db.createCollection("emp",{capped:false, size:8192});`</pre>

8.

<p>colection list보기

<pre class="prettyprint">`>show collections`</pre>

9.

<p>collection의 현재상태 및 정보분석

<pre class="prettyprint">`>db.emp.validate();`</pre>

10.

<p>collection의 이름변경

<pre class="prettyprint">`>db.emp.renameCollection("employee")`</pre>

11.

<p>Collection의 삭제

<pre class="prettyprint">`>db.employee.drop();`</pre>

12.

<p>collection에 데이터 INSERT

<pre class="prettyprint">`>db.emp.insert({eno:1101,name:"JIMMY"});`</pre>

13.

<p>collection에 데이터 UPDATE

첫번째 인자는 일치 조건이고, 두번째는 업데이트할 값, 세번째는 옵션이다.

<pre class="prettyprint">`>db.emp.update({eno:1101, age: { $lte: 20 }}, {$set:{fname:"JOO"}, {multi: false}});`</pre>

14.

<p>collection에 데이터 SELECT

인자가 없으면 모든 documents 조회한다. 메서드 체이닝으로 정렬도 가능하다.

<pre class="prettyprint">`>db.emp.find({url:"msalt.net"});
>db.emp.find().sort({eno:-1});
`</pre>
