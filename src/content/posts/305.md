한 동안 손을 못대고 있다가 갑작스럽게 다시 시작했다. 여름에 해커톤이 있다는 첩보를 접수했기에 거기에 사용 될라믄 빨리 만들어야겠다 싶어서. 서두르고 있다. 1월에 마지막으로 PoC하다 말고 손을 놨더라. 얼른 PoC를 정리해서 코드를 올려보았는데, PoC의 마무리는 검증으로!

Travis가 Window용, Linux용 바이너리를 생성해서 올려주었다. [T.View Release](https://github.com/msaltnet/T.Viewer/releases/tag/ver0.0.1)

![](/images/posts/305/002.gif)

## 점검항목 정하기

몇가지 항목들을 뽑아 보았다. 실사용에 걱정되는 부분들 위주로.

1. 로그 정상 출력 확인

- 로그 3만라인 이상 버벅거림 없는지

- 드랍 없이 출력되는지

2. 동시에 여러 탭이 동작 가능한지 확인

- 로그 탭에 10개까지 추가

- 서로 다른 간단한 필터 적용

3. 다양한 기기 동작 확인

- 저사양 pc, 노트북

- 윈도우, 리눅스에서도 잘 동작하는지

## 로그 정상 출력 확인

우선 기본적으로 로그가 빠짐없이, 버벅거림 없이 출력이 되는지 확인부터 해봤다.

## 동시에 여러 탭이 동작 가능한지 확인

탭마다 서로 다른 필터를 적용해서 10개를 하드코딩해 놨다. 일단 내 PC기준으로 큰 버벅거림은 없었다. 의외로 CPU도 많이 안쓰다. 크롬답게 메모리를 많이 쓴다;;

## 다양한 기기 동작 확인

저사양 PC의 확인은 내 노특에서 일단 확인해보는 수준으로 정리하고, 리눅스에서도 잘 동작하는 것을 확인했다.

## 마치며

PoC를 마치니까 뭔가 큰 짐을 덜어낸것 같다. 앞으로 달리기만 하면 될 듯하다. 물론 곧 나를 막아서 문제를 만나겠지만ㅋㅋ 그게 개발의 묘미쥐~ㅎ
